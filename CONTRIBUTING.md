# Contributing to AI Design Skills

Thank you for being here! 🎨  
This is a community-driven repository and every contribution — big or small — helps make it better.

---

## 📌 What You Can Contribute

- **Prompts** — AI prompts you use in your design workflow
- **Workflows** — Step-by-step processes combining design + AI
- **Case studies** — Real projects where AI played a role in the design
- **Resources** — Useful tools, articles, links, or references
- **Fixes** — Typos, outdated content, broken links, clearer wording

---

## 🚀 How to Contribute

1. **Fork** this repository
2. **Create a branch** with a descriptive name:
   ```
   git checkout -b add/midjourney-prompts-for-ux
   ```
3. **Make your changes** following the guidelines below
4. **Commit** with a clear message:
   ```
   git commit -m "add: logo design prompts for ChatGPT"
   ```
5. **Open a Pull Request** — describe what you added and why it's useful

---

## 📝 Content Guidelines

- Write in **plain Markdown** (`.md`)
- Use **clear, simple language** — this repo is for all levels
- Add a short **intro** at the top of any new file explaining what it covers
- If you include AI-generated content, note which tool was used
- Cite or credit sources where relevant
- Use inclusive, respectful language throughout

---

## 📂 Where to Put Things

| Content type | Folder |
|---|---|
| AI prompts | `/prompts` |
| Design workflows | `/workflows` |
| Case studies | `/case-studies` |
| Tools and links | `/resources` |

If your contribution doesn't fit a folder, open an issue first and we'll figure it out together.

---

## 🖼️ Adding Images or Assets

- Prefer **SVG or PNG** for diagrams and screenshots
- Keep file sizes reasonable — use Git LFS for large files
- Add a short description or caption where helpful
- Only submit assets you have the right to share

---

## 🔍 Review Process

- Pull requests are reviewed by maintainers within a few days
- You may receive feedback or suggestions — that's normal and welcome
- Be patient and open to discussion

---

## 💬 Questions or Ideas?

Open a [GitHub Discussion](../../discussions) or an [Issue](../../issues) — no question is too small.
