# Case Studies

Real examples of AI being used in the design process — what worked, what didn't, and what was learned.

## Why Case Studies Matter

Prompts and workflows are only half the picture. Case studies show **AI in context**: the messy, iterative reality of applying these tools to actual projects.

## Structure

```
case-studies/
├── [your-case-study-slug]/
│   ├── README.md          # The case study writeup
│   └── assets/            # Screenshots, before/afters, outputs
```

## Case Study Template

Copy the structure below into a new folder to share your own:

```markdown
# Case Study Title

**Author:** Your name / handle
**Date:** YYYY-MM
**Design phase(s):** Discovery / Ideation / Validation / Handoff
**AI tools used:** e.g. ChatGPT, Midjourney, GitHub Copilot

## The Challenge

What problem were you solving? What constraints did you have?

## How AI Was Used

Be specific — which prompts, which tools, at which stage.

## Results

What did the AI-assisted approach produce? Include visuals where possible.

## Key Takeaway

The one insight you'd share with another designer.
```
