# Resources

A curated list of tools, articles, courses, and communities for designers working with AI.

---

## 🤖 AI Tools for Designers

| Tool | Category | Notes |
|---|---|---|
| [ChatGPT](https://chat.openai.com) | Text / reasoning | Great for synthesis, writing, prompt iteration |
| [Claude](https://claude.ai) | Text / reasoning | Strong at long-context analysis and nuanced writing |
| [Midjourney](https://midjourney.com) | Image generation | Best-in-class aesthetic quality |
| [DALL·E 3](https://openai.com/dall-e-3) | Image generation | Integrated into ChatGPT; good for concept sketches |
| [Firefly](https://firefly.adobe.com) | Image generation | Adobe ecosystem, commercially safe |
| [Galileo AI](https://www.usegalileo.ai) | UI generation | Text-to-UI, Figma export |
| [Uizard](https://uizard.io) | UI generation | Sketch-to-wireframe, rapid prototyping |
| [Relume](https://relume.io) | Sitemap & wireframes | AI-generated website structures |
| [Framer AI](https://framer.com) | Website building | AI-assisted responsive design |
