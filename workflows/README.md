# Workflows

Step-by-step guides that combine AI tools with design practice.

## Structure

```
workflows/
├── discovery/         # Research, problem framing, competitive analysis
├── ideation/          # Brainstorming, concept generation, sketching aids
├── validation/        # Usability testing, feedback loops, metrics
└── handoff/           # Specs, annotations, developer collaboration
```

## Workflow File Format

Each workflow document should include:

| Section | Description |
|---|---|
| **Overview** | What design problem this workflow solves |
| **Tools needed** | AI tools + design tools required |
| **Time estimate** | Rough time to complete |
| **Steps** | Numbered, actionable steps |
| **Tips** | Gotchas, shortcuts, or variations |
| **Output** | What you'll have at the end |
